# 灯光方案库

每场镜头组先定灯光方案，再写镜头。方案格式：类型 / 核心情绪 / 选用光型 / 主光 / 轮廓光 / 氛围 / 色彩倾向。

## 常用光型

| 光型 | 效果 | 典型用途 |
| --- | --- | --- |
| 逆光（硬） | 主体背光，轮廓锐利 | 剪影、神化、压迫、觉醒 |
| 分割光 | 光线从门缝/百叶窗切入，明暗分界 | 卑微、恐惧、悬念、对峙 |
| 丁达尔光（体积光） | 光束穿过尘埃/雾气可见 | 神圣、神秘、觉醒、力量 |
| 眼神光 | 瞳孔内光点 | 生命力、情绪、主体醒目 |
| 伦勃朗光 | 面部一侧三角光区 | 经典人像、威严、叙事 |
| 侧逆光 | 从侧后方勾勒轮廓 | 分离人物与背景 |
| 鬼光（底光微补） | 底部微光 | 诡异、压迫、蓄势 |
| 蝴蝶光 | 高位正面光，鼻下蝶形阴影 | 优雅、主角光环 |
| 轮廓光 | 锐利勾边 | 突出主体、氛围勾边 |
| 窗外过曝 | 窗外亮度高于室内 | 预示未来、格局、希望 |

## 情绪 → 灯光映射（经验值，可叠加）

| 情绪/情节 | 光型组合 | 色彩倾向 |
| --- | --- | --- |
| 觉醒/力量暴涨/神秘 | 逆光（硬）+ 分割光 + 丁达尔光 + 眼神光 | 冷蓝青白调（高光冷白/阴影深蓝） |
| 威严/救赎/震撼 | 伦勃朗光 + 侧逆光 + 鬼光 + 眼神光 | 治愈时刻掌心金光为主光源，暖金与冷环境强反差 |
| 收服完成/格局打开 | 逆光（硬）+ 锐利轮廓光 + 蝴蝶光 | 冷蓝主调带暖金残余（神迹余温） |
| 卑微/恐惧 | 分割光从门缝切入，面部半明半暗 | 冷蓝加重 |
| 神迹/温暖 | 暖金色光晕扩散 | 冷背景衬托暖金 |
| 悲壮/牺牲 | 逆光剪影 + 升格 | 冷灰/雪白 |

## 色温参考

- 冷硬日光：约 7800K（清晨/窗外冷光、冷峻、科技感）
- 模拟日光：约 6500K（室内日景主光）
- 暖金光：治愈、神迹、情感温度（掌心发光等特效光源）

## 提示词中的灯光写法（模板）

- 主光：从右侧窗外射入的冷硬日光（7800K），切割人物半边脸。
- 轮廓光：左侧后方硬逆光勾勒肩颈轮廓，发丝边缘带冷白光边。
- 氛围：室内漂浮细微光尘，百叶窗缝隙投下条纹状阴影。
- 色彩倾向：冷蓝青白调（高光冷白/阴影深蓝）；或冷蓝主调中带暖金残余。

## 输出要求

- 每场必须给出灯光方案块（类型/核心情绪/选用光型/主光/轮廓光/氛围/色彩倾向），再列本场镜头。
- 用户要求保留"场景光/体积光/调色"列时，逐镜头补全这三列；要求删除时不输出。
