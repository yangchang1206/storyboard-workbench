# 特殊视角与构图

## 特殊视角库（每场点缀 1-2 个，必须有叙事逻辑）

| 视角 | 手法 | 叙事用途 |
| --- | --- | --- |
| 窗外窥视 | 透过窗户拍室内/室外 | 窥视感、孤独感、格局（窗外过曝预示未来） |
| 镜中倒影 | 镜面反射构图 | 双重自我、审视、身份对照 |
| 地面反射 | 湿地面/玻璃倒影 | 情绪延展、氛围 |
| 门缝视角 | 门缝分割光切割人物 | 卑微、恐惧、悬念、入场 |
| 剪影/影子 | 逆光剪影 | 神化、压迫、牺牲、神秘 |
| 前景遮挡 | 手掌入画、肩头入画、物件入画 | 层次、压迫、代入 |
| 主观视角（POV） | 角色眼中所见 | 自我见证、沉浸 |
| 高空/俯拍 | 俯拍人物 | 渺小感、命运感 |

## 9:16 竖屏构图铁律

- 主体保持在画面上 1/3 位置（视觉中心）。
- 特写控制在画面中央区域。
- 双人对话：一人一侧；过肩镜头中对方面部位置保持在安全区。
- 窗外/镜中画面保持竖幅构图，避免横向元素占满画面。
- 预留字幕区：重要画面元素不要落在底部字幕区域。
- 环绕与横移幅度收敛，运镜优先垂直与纵深方向。

## 切换逻辑

- 硬切：常规镜头衔接（可标注"硬切（反应）""硬切（觉醒瞬间）"说明承接意图）。
- 叠化/淡出：时间流逝、回忆、情绪沉淀、场次结束。
- 闪回转场：画面转为横屏宽幅冷蓝调（或黑白），可加升格慢动作，标注"转场：闪回"。

## 构图写作示例

- 极远景定场后缓慢推进，人物从门框光影中走入冷蓝色室内。
- 低角度仰拍，以跪地三人的高度仰视窗前逆光而立的主角，高大威严如神祇。
- 过肩近景，从对方肩头后方拍摄主角，掌心接触点暖金光晕扩散。
