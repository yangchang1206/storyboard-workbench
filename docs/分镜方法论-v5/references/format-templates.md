# 输出格式模板

五种格式按用户要求选择；用户已确认后续集数默认模板 E（DeepSeek 总结计算版），输出前告知可切换。

## 模板 A：即梦提示词版（每镜头一段完整提示词）

每场先给灯光方案块，再逐镜头输出可直接粘贴进即梦的提示词：

```
即梦提示词 镜头X-Y：
电影级竖屏画面，9:16比例，[场景]。[人物动作]。[运镜描述]。[光线/氛围]。[情绪]。
```

- 灯光方案块格式：类型 / 核心情绪 / 选用光型 / 主光 / 轮廓光 / 氛围 / 色彩倾向。
- 示例：
  即梦提示词 镜头1-2：
  电影级竖屏画面，9:16比例，人物面部特写，百叶窗条纹阴影切割半边面庞。他闭眼、眉头微蹙、睫毛微颤，猛然睁眼——瞳孔深处骤然亮起璀璨金光，如液态金属般流淌。镜头采用希区柯克变焦（dolly zoom effect）：背景急速压缩、面部放大，产生眩晕震撼的空间扭曲感。冷蓝光与金色光芒在面庞上交织碰撞，满画面微尘粒子飞舞。情绪：觉醒、力量暴涨、震撼。

## 模板 E：DeepSeek 总结计算版（默认）

用户说"先总结、计算，再出分镜"或指定参考 DeepSeek 分享/回答格式时使用。结构固定为六段，每段小节标题照抄，逐段输出：

### 结构总览

1. **一、人物台词、动作与情绪总结**
   - （一）台词总览（按出场顺序）：表头 `序号 | 人物 | 台词 | 字数 | 情绪状态 | 语速 | 台词时长`
   - （二）动作总览：表头 `序号 | 人物 | 动作 | 动作时长`
   - （三）情绪曲线：箭头链（如 温馨→感慨→坚定→满足→温情→欢乐→圆满）
   - （四）断点规划（N 个断点，均 ≤30 秒）：表头 `断点 | 内容 | 台词时长 | 动作时长 | 总时长`，末行"合计"
2. **二、第X集 分镜头脚本**
   - 按断点分组，组标题：【断点N】内容摘要 — 生成片段N
   - 每镜头：【镜头N · 断点N】+ 字段行：转场 / 景别·运镜（含速度标注与时长）/ 画面内容 / 台词 / 情绪标记
   - 每组末尾：【断点N】（本段共Xs，≤30秒）
3. **三、总时长统计**：表头 `断点 | 内容 | 镜头 | 总时长`，末行合计（X 个镜头 / N 个片段 / 总时长）
4. **四、台词时间分配对照表**：表头 `镜头 | 说话人 | 台词 | 字数 | 语速 | 时长`
5. **五、本集镜头角度应用说明**：表头 `镜头 | 角度 | 理由`，逐镜头给理由
6. **六、本集核心视觉设计建议**：表头 `视觉元素 | 处理方式`
7. 结尾行："全剧分镜脚本已全部完成。"

### 硬性规则

- **断点即生成片段**：即梦单次生成上限约 30 秒，每个断点总时长必须 ≤30s；先把全集合成 N 个断点（通常 4-6 个），再写镜头。v5 起按"满负荷打包"原则，每个片段尽量压到 26~29.5s（收尾动作段可短至 15~20s），不牺牲语义完整。
- **语速口径（多档·情绪仪表，v5）**：喃喃/失神/OS 内心独白 3字/秒；普通对白/正式质询 3.5字/秒；对抗性台词（逼宫、施压、断然拒绝、咬牙切齿威胁）4字/秒；短促惊呼/兴奋爆发/孩子欢呼 5字/秒。台词分配对照表每行必须标注语速档位。
- **台词时长计算**：时长 = 字数 ÷ 语速档，精确到 0.1s（例：33÷4.0≈8.3s；38÷3.5≈10.9s；22÷3.5≈6.3s）。不再统一取 0.5s 粒度。
- **镜头时长**：有台词镜头 = 台词时长 + 0.2~0.5s 呼吸余量（开口前/收尾后气息）；无台词镜头按动作/氛围节奏 1.5-3s（结尾定格可 6s+）。
- **长台词细分**：一个人物台词镜头超 8s 必须细分——按 `references/pacing-and-revision.md` 的"五种细分手法"（①反应镜头穿插 ②语义断点切镜 ③动作与台词并行 ④物件/细节空镜 ⑤OS 画面错位）拆成多个镜头；单镜头台词 8-20 字为宜；每个切点必须写明切点理由（反应/动作/物件/景别变化），无理由的切就是乱切。
- **动作时长**：单动作 1.5-2s，连续动作（点火、拥抱、烟花绽放）2.5-3s。
- **转场写法**：硬切（可标注"接X集结尾""空间切换""动作接续"）；叠化（画面渐暗/淡出）。
- **景别/运镜写法**：`景别（主体），角度/运镜（正常速度），Xs`，例：`近景→特写·面部（林旭东），低角度仰拍（正常速度），11s`。
- **角度与视觉建议必须逐镜头/逐元素给理由**，不许空泛。
- **数值一致性**：断点规划表、分镜组内小结、总时长统计三处总时长必须一致；合计由明细现算（如 22.5+17+28.5+21.5+9=98.5≈99s），不得直接照抄旧值。
