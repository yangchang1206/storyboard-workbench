# 导演进阶八规则（AI 生成效率与镜头语言版）

> 版本：v5 新增。在 v4 导演七规则（`director-rules.md`）之上叠加生效；来源：对比第 37~40 集三份成熟分镜（38 对话对峙/39 台词交锋/40 群像反应）提炼的精华，每条标注出处集数。
> 使用顺序：先定义**集型**（规则三）→ 按集型定机位与灯光策略 → 逐镜生成时执行七规则 + 本文件命中项 → 交出自检清单核对。

## 规则八：语速多档化 · 情绪仪表（源自 38/39/40）

语速不再是固定值，而是**情绪强度仪表**。台词分配对照表每行必须标语速档位与口径。

| 语速档 | 字/秒 | 适用情绪/人物状态 | 示例 |
| --- | --- | --- | --- |
| 喃喃档 | 3.0 | 失神、自问、内心挣扎、气若游丝 | "怎么会这样……" |
| 常态档 | 3.5 | 普通对白、正式质询、陈述事实 | 一般对话 |
| 对抗档 | 4.0 | 逼宫、施压、断然拒绝、咬牙切齿的威胁 | "你今天必须给我个说法！" |
| 惊呼档 | 5.0 | 短促惊呼、兴奋爆发、孩子欢呼、记者抢话 | "出事了！他来了！" |

- **台词时长 = 字数 ÷ 语速档**，精确到 0.1s（如 33÷4.0≈8.3s），不再统一取 0.5s 粒度。
- 同一人物在情绪递进中语速可升档（如先 3.5 质问→4.0 逼宫），对照表要体现变化。
- 时长取整后，**镜长 = 台词时长 + 0.2~0.5s 呼吸余量**（开口前/收尾后的气息），让 AI 口型与镜头不打架。

## 规则九：灯光是剧情变量（源自 38 断崖 + 40 贯穿色）

灯光方案不是"氛围布置"，而是**参与叙事的剧情变量**。除常规七要素（类型/情绪/光型/主光/轮廓/氛围/色彩）外，追加：

1. **情绪断崖**：同一片段内部允许"前→后"光变，转折点写进灯光方案。示例（38 集）：大门踹开前大厅用鬼光闷压（冷灰），踹开后逆光硬光涌入（冷白强光）——破局震撼是光做出来的。
2. **贯穿色**：一集内把关键道具/神物光效做成色彩主题（如"幽蓝生命荧光贯穿全集"），片段收尾保留余光做收束呼应。
3. **双认证**：同一神物在多个载体重复光效（如证书顶光与木匣蓝光呼应），形成跨镜头的证据锚。
4. 每个片段的灯光方案必须写"本片段情绪弧线内的光变点"，无光变的片段可写"稳定光"。

## 规则十：集型机位策略（源自 40）

出分镜前先给本集**定义集型**，机位比例自查按集型解释偏差，而非机械达标：

| 集型 | 判定特征 | 机位倾向 |
| --- | --- | --- |
| 对话对峙集 | 双人/三方言语交锋为主 | 正面 40%+（正反打需要）、过肩占比上浮 |
| 动作冲突集 | 追逐、打斗、夺物 | 侧面 30%+、仰拍/俯拍上浮 |
| 群像反应集 | 多人围观、集体反应、现场审判 | 正面 40%+（多人情感落点需正面肌肉与眼神） |
| 情感戏 | 独处、回忆、告白 | 背面/侧面上浮，特写占比高 |

- 机位自查表必须写**偏差理由**："本集为群像反应集，正面 42% 用于代表1/伊万/代表2/外商/安娜的情感落点"——无剧情理由的偏差才是违规。
- **力量归属动态化**：角度理由中"谁更有力量"随剧情流动（反抗前 vs 反抗瞬间 vs 反转后），不是全剧贴同一个标签。

## 规则十一：跨片段台词连续性（源自 39）

长台词跨两个生成片段时：

1. 台词分配对照表标注"**语义断点拆分·上句/下句（跨片段）**"。
2. 文末加注脚："镜头X台词顺延至镜头Y继续，**语音连续不中断**"。
3. 断点规划时优先把语义完整句放进同一片段；实在放不下才跨，且切点必须选在语义停顿处（逗号级，不切破词）。
4. 镜头时长照旧给足全句，跨片段的两个镜长分别按各自含有的台词字数计算。

## 规则十二：运镜术语双语标注（源自 39）

每个镜头运镜**中文 + 英文术语双标**，英文术语可直接喂即梦/AI 工具：

- 斯坦尼康跟拍（steadicam follow）
- 缓慢推近（slow dolly in）
- 过肩近景（over-the-shoulder close-up）
- 缓慢上摇/左移（slow pan up / slow pan left）
- 缓慢后拉（slow pull back）
- 斯坦尼康环绕（steadicam orbit）
- 手持微晃（handheld micro-shake）
- 低角度仰拍（low angle shot）
- 希区柯克变焦（dolly zoom effect）

写法："镜头采用斯坦尼康环绕（steadicam orbit）逆时针绕主体旋转半圈"。

## 规则十三：道具符号系统（源自 38/39/40）

1. **铺垫→引爆**：关键道具（木匣、锁扣、证书）前片段做景深虚化铺垫，爆点镜头用特写+希区柯克变焦引爆悬念，写清"前 N 片段铺垫、片段 X 引爆"。
2. **次级证据**：道具细节创造画面内的第二重信息（如"放大镜镜面反出灵芝蓝光，形成镜中之物的次级证据镜头"）。
3. **道具锚点**：同一道具外观跨镜头逐字一致（与角色锚点同规则）。

## 规则十四：走位叙事（源自 40）

用**站位与人群流动**表达立场、关系与判决，不靠台词：

1. **空间判决**：写清人群绕开的路径（"人流绕开维克多，做无声的空间判决"）——谁被绕开谁就输了。
2. **中轴对称对峙**：主角始终站轴线中央，对手/贵人从一侧进入，形成对峙构图。
3. **立场转换镜头**：角色转身/离席等动作镜头，用缓慢后拉展示"背对旧立场、面向新阵营"的转换。
4. 站位轴线写进画面内容与视觉建议，并说明符号含义。

## 规则十五：片段满负荷打包（源自 39）

- 每个生成片段尽量压到接近 30s 上限（26~29.5s），减少片段数、最大化单次生成效率；收尾动作段可短至 15~20s。
- 满负荷打包不得牺牲断点语义完整性：超载时优先移动整句台词/整段动作到相邻片段，不硬切。

## 体态细节密度底线（源自 40）

- 主角、反派、关键配角每个出镜镜头至少一个**生理细节**（踉跄半步/唾沫横飞/胸口起伏/扒住同行肩膀/手垂在身侧微微发抖），禁止干站干说。
- 群像镜头给 2~3 人分配不同细节（一人探身、一人后退、一人低头），避免集体同姿势。
