# 导演七规则（分镜表演强化版）

> 版本：v4 新增。生成**每一个镜头**前必须对照本文件；与模板 E、长台词细分规则叠加生效。
> 使用顺序：先定镜头任务（这台词/动作要传达什么）→ 按七规则逐条检查 → 写进镜头描述。

## 规则一：情绪力量感 · 肌肉导演法

用**物理指令**替代文学形容词，让人工智能画面可执行、可复现。

| 维度 | 要素 | 写法示例 |
| --- | --- | --- |
| 面部肌肉 | 颧大肌收缩角度、眼轮匝肌状态、眉部位置、鼻翼翕张 | "颧大肌牵引嘴角向上移动3°，眼神冰冷" |
| 肢体联动 | 手指动作、身体前倾/后仰、呼吸节奏 | "手指有节奏敲击桌面，前倾半拳距离" |
| 时间轴 | 动作持续时间、停顿节奏、眨眼频率 | "停顿0.8秒，快速眨眼两次，喉结滚动" |

写法模板："颧大肌牵引嘴角向上移动X°，眼神冰冷，手指有节奏敲击桌面"。

## 规则二：长动作拆解 · 动作链法则

一个超过 2 秒的完整动作拆成四步链路，每步一个镜头：

| 步骤 | 镜头内容 | 目的 |
| --- | --- | --- |
| ① 起始特写·发力点 | 手指攥紧、指节发白、青筋暴起 | 建立力量锚点 |
| ② 过程中景·跟拍 | 动作轨迹、速度感、1.2倍速 | 展示动作连贯性 |
| ③ 结果特写·落点 | 升格慢动作、声音强化 | 强化冲击力 |
| ④ 反应近景·对手 | 瞳孔微缩、身体后仰、喉结滚动 | 侧面印证威慑力 |

## 规则三：机位平衡 · 三问原则

每个镜头生成前必问三个问题，答案写入镜头机位/角度说明（禁止空泛写"机位合理"）：

| 问题 | 决定 |
| --- | --- |
| 观众应该站在谁的视角？ | 正面（旁观）/ 背面（代入）/ 过肩（关系） |
| 这一镜要突出什么？ | 表情→正面；动作→侧面；悬念→背面 |
| 谁在这一刻更有力量？ | 仰拍（强势方）/ 俯拍（弱势方） |

## 规则四：台词情绪标签

台词行首标注情绪标签，供生成与剪辑快速定位：

| 标签 | 用途 |
| --- | --- |
| `[angry outburst]` | 愤怒爆发 |
| `[sarcastic]` | 讽刺 |
| `[cold threat]` | 冷厉威胁 |
| `[gentle whisper]` | 温柔低语 |
| `[panicked scream]` | 惊慌尖叫 |
| `[bitter laugh]` | 苦笑 |

## 规则五：动作终点态

动作必须写明**结束状态**，禁止动作截断。

- 正确："他转身，在门框处停顿半秒，然后彻底消失在门后"
- 正确："他转身，走到门口，推开门，消失在走廊尽头"
- 禁止：只写"他转身离开"

## 规则六：机位比例控制

全片机位占比参照（镜头多时按比例自查，避免单一机位刷屏）：

| 机位 | 目标占比 | 核心用途 |
| --- | --- | --- |
| 正面 | 30-40% | 表情捕捉、交流 |
| 侧面 | 20-30% | 动作展示、过渡 |
| 背面 | 15-25% | 代入感、悬念 |
| 过肩 | 5-10% | 对话关系 |
| 俯拍/仰拍 | 各 5-10% | 力量对比 |

## 规则七：角色锚点锁定

- 每个断点（生成片段）开头固定角色形象，如"沿用上一镜的黑色夹克、短发、左眉有疤的形象"。
- 防止 AI 跳脸：同一角色跨镜头时，外貌描述**逐字复制**，不得改写。
- 换场景/换阶段（高中→大学→职场）时才更新形象锚点，并注明阶段。

## 自检清单（每个镜头）

- [ ] 情绪是否用物理指令（肌肉/肢体/时间轴）表达，而非形容词？
- [ ] 长动作是否按动作链四步拆镜？
- [ ] 机位三问是否有明确答案（视角/突出/力量）？
- [ ] 台词是否带情绪标签？
- [ ] 动作是否写了终点态？
- [ ] 角色外貌是否与上一镜逐字一致？
